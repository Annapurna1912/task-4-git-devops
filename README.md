# Task 4 - Version Controlled DevOps Project

## Objective

Manage a DevOps project using Git best practices.

## Tools Used

- Git
- GitHub

## Git Branching Strategy

- `main` - Stable production branch
- `dev` - Development branch
- `feature` - Feature development branch

## Git Workflow

1. Initialized a Git repository.
2. Created the `main` branch.
3. Created the `dev` branch.
4. Created the `feature` branch.
5. Added project documentation.
6. Committed changes using meaningful commit messages.
7. Pushed all branches to GitHub.
8. Created a Pull Request from `feature` to `dev`.
9. Merged the feature into `dev`.
10. Created a Pull Request from `dev` to `main`.
11. Merged the development changes into `main`.
12. Created Git tag `v1.0.0`.
